The ``2-matrix_divided`` module
=================================

Import the function:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Regular division, rounded to 2 decimal places:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

The original matrix is left unchanged:

    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Works with floats and negative numbers too:

    >>> matrix_divided([[1.5, -2.5], [3, -4]], 2)
    [[0.75, -1.25], [1.5, -2.0]]
